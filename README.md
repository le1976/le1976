## Projetos em destaque

### [VerdePrioriza](https://github.com/le1976/verdeprioriza)

Sistema de apoio à decisão que combina dados públicos e análise espacial multicritério para identificar e explicar áreas prioritárias para restauração, proteção de recursos hídricos e planejamento ambiental.

A análise com referência ambiental de 2024 abrangeu **20 municípios** e identificou **1.045 áreas prioritárias**, somando **51.810,1 hectares**. O dashboard permite explorar os resultados por município, comparar áreas e consultar fichas técnicas.

Desenvolvido com Python, PostgreSQL/PostGIS e Streamlit.

[Apresentação executiva em PDF](https://github.com/le1976/verdeprioriza/blob/main/docs/presentation/VerdePrioriza_10F_Portfolio.pdf) · [Visão do dashboard](https://github.com/le1976/verdeprioriza#dashboard-final)
